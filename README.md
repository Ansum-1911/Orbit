# ORBIT

**Your life, organized in motion.**

ORBIT is a student-focused daily planner. This repository's `index.html` is based on the latest `ORBIT2.html` provided for this release.

## Status

ORBIT is an early-stage project. Features may change and the current release should be tested before being relied on for important schedules. If you find a problem, please open an issue with steps to reproduce it.

## Run ORBIT locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.

The current app is a single-file static web app; no build step or server is required for local use.

## Data and privacy

- The current version is designed to store planner data in the browser on the device where it is used.
- There is no ORBIT account or cloud-sync service in this repository.
- Your data may not transfer between browsers or devices. Use the app's backup/export feature before clearing browser data or switching devices.
- Do not commit planner exports, private schedules, credentials, or other personal data.
- Review the source to understand third-party resources the page may load.
