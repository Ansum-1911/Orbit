# Contributing to ORBIT

Thanks for considering a contribution.

- For large changes, open an issue first to discuss the approach.
- Keep pull requests focused and explain the problem being solved.
- Do not include personal planner exports, private schedules, credentials, or secrets.
- Do not claim a feature is tested unless you tested it.
- Include browser/device details and steps to reproduce when reporting bugs.

## Manual checks

When relevant, test task creation/editing/completion, schedule generation, fixed-time conflicts, persistence after refresh, JSON and CSV export, JSON import using disposable test data, and mobile navigation.
